Getting Started

TECMP-Tool allows you to build, modify, and export network packets with specific focus on the Technically Enhanced Capture Module Protocol (TECMP).

Basic Workflow

  1. Create a protocol stack by adding one or more protocols
  2. Configure each protocol's parameters
  3. Optionally wrap the stack in TECMP encapsulation
  4. Generate and preview the packet
  5. Export the packet in your desired format
Tip: Start with basic protocol configurations and then adjust the parameters to meet your specific needs.

TECMP Protocol

The Technically Enhanced Capture Module Protocol (TECMP) is a proprietary protocol used for advanced network diagnostics and testing.

TECMP Structure

A TECMP packet consists of:

  • Device ID (2 bytes): Identifies the source device
  • Counter (2 bytes): Message sequence counter
  • Version (1 byte): Protocol version (typically 3)
  • Message Type (1 byte): Defines the message purpose (0x03 for Logging Stream)
  • Data Type (2 bytes): Specifies the encapsulated protocol (0x80 for Ethernet)
  • Device Flags (2 bytes): Control flags (EOS, SOS, SPY, Multi-Frame)
  • Payload: The encapsulated data

Data Types

Value Protocol Description
0x02 CAN Controller Area Network
0x03 CAN-FD CAN with Flexible Data-Rate
0x04 LIN Local Interconnect Network
0x08 FlexRay Automotive network protocol
0x10 UART/RS232 Serial communication
0x80 Ethernet Standard Ethernet frames
Note: The data type is automatically detected based on the encapsulated protocols.

Building Packets

Adding Protocols

To add protocols to your stack:

  1. Click the Add Protocol button in the toolbar
  2. Select a protocol from the list
  3. Configure the protocol parameters in the dialog
  4. Click OK to add it to the stack

TECMP Encapsulation

To encapsulate your protocol stack in TECMP:

  1. Build your inner protocol stack first
  2. Go to Encapsulation ? Add TECMP...
  3. Configure the TECMP parameters
  4. Click OK to apply the encapsulation
Important: Once TECMP encapsulation is applied, you cannot add new protocols to the inner stack until you remove the encapsulation.

Using TECMPPacketBuilder

The application uses a specialized builder for TECMP packets with a fluent interface:

TECMPPacketBuilder builder = new TECMPPacketBuilder();
packet = builder
  .with_device_id(0x0080)
  .with_counter(324)
  .with_version(3)
  .with_message_type(0x03)
  .with_data_type(0x80)
  .with_device_flags(0x000F)
  .with_payload(innerPacketData)
  .build();

Exporting

Export your packet in various formats:

  • PCAP: Save as a Wireshark-compatible capture file
    • Click File ? Export ? PCAP...
    • Choose a filename and location
    • Open with Wireshark or similar tools
  • JSON: Export configuration as structured data
    • Click File ? Export ? JSON...
    • Contains all protocol parameters
    • Useful for documentation or sharing
  • Text: Generate a human-readable dump
    • Click File ? Export ? Text...
    • Detailed layer-by-layer representation
    • Includes all fields and values

Transmission Strategies

Configure how packets are transmitted:

  • Single: Basic transmission mode
    • One packet at a time
    • Simplest configuration
    • Default strategy
  • Priority: Quality of Service
    • Assign priority levels (0-7)
    • Configure via Strategy ? QoS...
    • Higher numbers = higher priority
  • Concatenation: Batch processing
    • Send multiple packets in sequence
    • Configure via Strategy ? Concatenation...
    • Set chunk size and gap timing

Advanced Topics

Segmentation

For large payloads, TECMP supports automatic segmentation:

  • Payloads larger than the maximum segment size will be split
  • The SoS (Start of Segment) flag is set on the first segment
  • The EoS (End of Segment) flag is set on the last segment
  • Counter values increment for each segment

Validation

The tool performs automatic validation of packets:

  • Checks for valid device ID, message type, and data type
  • Ensures proper flag combinations
  • Validates payload size against protocol limits
  • Can be disabled for special cases using disable_validation()
